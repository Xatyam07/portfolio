## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Xatyam07/portfolio.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
